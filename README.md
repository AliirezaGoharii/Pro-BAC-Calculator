# BAC Calculator (Vue.js)

An advanced and responsive web application built with Vue.js 3 and Tailwind CSS to estimate Blood Alcohol Content (BAC). This tool provides an intuitive user interface for tracking alcohol consumption and understanding its potential effects over time.

### Disclaimer

This tool is for entertainment and informational purposes only. The BAC calculation is an estimate based on the Watson Formula and should not be used for any legal or medical purposes. The result is not a substitute for professional advice. **Never drink and drive.**

### ✨ Features

* **Accurate Estimation:** Utilizes the Watson Formula, considering weight, height, age, and gender for a more precise Total Body Water calculation.
* **Fully Responsive Design:** A clean and modern UI that works seamlessly on desktops, tablets, and mobile devices.
* **Dynamic & Real-time Calculation:** Results update instantly as you add or remove drinks.
* **Persistent User Data:** Remembers your information (weight, height, etc.) and consumed drinks list using the browser's Local Storage.
* **Unit Conversion:** Easily switch between Metric (kg/cm) and Imperial (lbs/in) units.
* **Custom Drink Management:** Add custom drinks with specific volume and alcohol percentage, in addition to quick-add presets.
* **Visual Feedback:** The result is color-coded to visually represent different levels of intoxication.

### 🛠️ Tech Stack

* **Frontend:** Vue.js 3 (Composition API)
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Deployment:** GitHub Pages
