# 🍷 Pro BAC Calculator

An advanced, responsive, and user-friendly Blood Alcohol Content (BAC) calculator built with Vue.js 3, Vite, and Tailwind CSS.

---

### ⚠️ Disclaimer

This tool is for **entertainment and educational purposes only**. The calculated BAC is an estimate based on the Watson formula and should not be used for any legal or medical purposes. Alcohol affects individuals differently based on numerous factors. **Never drink and drive.** If you have been drinking, please use a designated driver, a ride-sharing service, or public transportation.

---

### ✨ Features

* **Accurate Estimation**: Uses the **Watson formula**, which considers weight, height, age, and gender for a more precise estimation of Total Body Water.
* **Fully Responsive**: Modern and fluid design that looks great on all devices, from mobile phones to desktop monitors.
* **Persistent State**: Automatically saves your information (weight, age, etc.) and consumed drinks list in the browser's local storage.
* **Unit Conversion**: Seamlessly switch between **Metric** (kg/cm) and **Imperial** (lbs/in) units.
* **Dynamic Drink Management**: Easily add preset drinks (beer, wine, shot) or create custom beverages with specific volumes and alcohol percentages.
* **Real-time Calculation**: The BAC result updates instantly with every change you make.
* **Sleek UI**: A beautiful glassmorphism-inspired interface with a vibrant gradient background.

---

### 🛠️ Tech Stack

* **Frontend Framework**: `Vue.js 3` (with Composition API)
* **Build Tool**: `Vite`
* **Styling**: `Tailwind CSS`
* **Icons**: `Lucide Vue Next`
